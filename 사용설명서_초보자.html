처음 한 번만 — 실행과 구글 계정 연결

01V3 압축을 새로운 폴더에 풀고 실행하기.bat을 더블클릭하세요. 처음 화면은 ① 계정 연결입니다.
02상단 프로필 확인

새 Morning Chill Rap 계정의 작업 프로필을 선택합니다. 없다면 + 채널 추가 → 국가 JP → 장르 모닝칠랩을 선택하세요. 다른 계정은 별도 프로필로 추가합니다.

03Google 연결 모듈 설치

OAuth_모듈_설치하기.bat 더블클릭. 최초 1회만 필요합니다. Python 3.10+와 인터넷 연결이 필요합니다.

04Google Cloud에서 OAuth JSON 만들기

Google Cloud Console → 프로젝트 선택/생성 → API 라이브러리에서 YouTube Data API v3 사용 → Google Auth Platform에서 앱 정보·대상 사용자 설정 → 클라이언트 만들기 → 데스크톱 앱 → JSON 다운로드.

테스트 상태라면 테스트 사용자에 새 Morning Chill Google 계정을 추가하세요. 실제 친구 계정마다 테스트 사용자 등록이 필요할 수 있습니다.

05프로그램에서 계정 연결

① 계정 연결 탭 → [1. OAuth JSON 선택] → [2. 새 계정으로 Google 로그인 및 연결]. 브라우저가 열리면 **새로운 Morning Chill 계정**을 선택하세요. 프로그램이 보여주는 계정 이메일/유튜브 채널 이름을 확인하고 승인합니다.

06장르만 골라 검색

② 장르별 채널 검색 → Morning Chill Rap 전용 일본어 검색어 선택 → API로 후보 자동 수집. 연결된 계정이 있으면 별도 API 키 없이 검색 가능합니다. 채널이 없는 조사 계정도 연결할 수 있습니다.

매일 쓰는 사용법

탭해야 할 작업
① 계정 연결현재 연결된 구글 이메일·채널명 확인, 계정별 연결/해제
② 장르별 채널 검색상단의 현재 작업 계정 경고를 확인하고 국가·장르별 검색
③ 후보·장르 검토영상 직접 감상 및 메모. 장르 정확도 검증에서 제외 영상까지 적합/제외/불확실 라벨 기록
④ 댓글 초안영상을 듣고 고유한 감상 입력, 수동 복사·게시
⑤ 국가별 성과YouTube Studio에서 확인한 실측 데이터 기록
⑥ 예약·도움말앱을 켜둔 동안 예약 API 검색, CSV/DB 백업
장르 정확도 숫자 읽기

추천 정밀도는 앱이 적합으로 추천한 라벨 표본 중 사람이 실제 적합으로 확인한 비율입니다. 제외 오류율은 앱이 제외했지만 사람이 적합으로 확인한 비율입니다. 표본이 적거나 불확실 라벨뿐이면 측정 전으로 표시하며 95% 달성을 주장하지 않습니다.

계정과 데이터를 안전하게 관리하기

Google 계정을 연결한다고 일본 현지 유튜브 홈 추천이 바뀌는 것은 아닙니다. 앱은 공식 데이터 API를 이용하는 조회 전용 도구입니다. VPN과 무관하며, 반복 자동시청·댓글 자동게시·좋아요·구독 매크로는 제공하지 않습니다.
비밀번호와 JSON을 보내지 마세요.

JSON 파일은 각 사용자가 자신의 PC에서 선택하며, 승인 토큰은 개인 PC의 %LOCALAPPDATA%\ZisuResearchStudio\oauth_tokens에 저장됩니다. 기존 ZISU V2 데이터를 유지하기 위해 데이터베이스는 삭제하지 않습니다. 기존 DB를 백업한 뒤 업데이트를 진행하세요.

자주 발생하는 오류

모듈이 없습니다 → OAuth_모듈_설치하기.bat 실행.

이 앱은 확인되지 않았습니다 / access blocked → Google Cloud의 테스트 사용자와 동의 화면 상태 확인. 개인 계정을 직접 테스트 사용자로 등록해야 할 수 있습니다.

데스크톱 앱이 아닙니다 → 웹 앱용 JSON이 아닌 데스크톱 앱 OAuth JSON 재발급.

유튜브 채널이 없습니다 → 조사 전용 계정은 채널 없이도 연결 가능(유튜브 API 사용 가능 여부는 Google 정책에 따라 확인 필요).

실행 안 됨 → 오류진단하기.bat 실행 후 로그 확인.
