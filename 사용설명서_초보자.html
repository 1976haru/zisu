처음 한 번만 — 실행과 구글 계정 연결

01V4.5.3 배포 ZIP을 새로운 폴더에 전체 압축 해제합니다. ZisuResearchStudio.exe와 _internal 폴더를 같은 위치에 두세요. 폴더를 분리하거나 EXE만 이동하면 실행되지 않습니다. EXE 배포판은 Python 설치가 필요 없고, Google OAuth 모듈도 별도로 설치할 필요가 없습니다.
02상단 프로필 확인

새 Morning Chill Rap 계정의 작업 프로필을 선택합니다. 없다면 + 채널 추가 → 국가 JP → 장르 모닝칠랩을 선택하세요. 다른 계정은 별도 프로필로 추가합니다.

03오프라인 검증 (선택)

GitHub Actions 아티팩트의 검증하기.cmd를 실행하고 해당 아티팩트의 ZIP을 지정합니다. ZIP SHA-256은 같은 아티팩트의 RELEASE_SHA256SUMS.txt, EXE SHA-256은 ZIP 내부의 SHA256SUMS.txt와 비교합니다. 네트워크와 OAuth 로그인 없이 격리 테스트 데이터만 사용합니다. Sandbox가 켜져 있으면 자동 실행하고, 없으면 현재 PC에서 검사합니다.

04실전 검증 마지막에 Google Cloud OAuth 설정

Google Cloud Console에서 YouTube Data API v3 및 데스크톱 OAuth를 설정하는 절차입니다. 이번 오프라인 설치 검증에는 필요하지 않습니다. 실제 Google 계정 설정과 승인은 코드 검증을 마친 뒤 마지막 실전 단계에서 합니다.

테스트 상태라면 테스트 사용자에 Morning Chill Google 계정을 추가하세요.

05프로그램에서 계정 연결

① 계정 연결 탭 → [1. OAuth JSON 선택] → [2. 새 계정으로 Google 로그인 및 연결]. 브라우저가 열리면 새로운 Morning Chill 계정을 선택하세요. 프로그램이 보여주는 계정 이메일/유튜브 채널 이름을 확인하고 승인합니다. 이 단계는 실제 OAuth 실전 검증에서만 진행합니다.

06장르만 골라 검색

② 장르별 채널 검색 → Morning Chill Rap 전용 일본어 검색어 선택 → API로 후보 자동 수집. 연결된 계정이 있으면 별도 API 키 없이 검색 가능합니다. 채널이 없는 조사 계정도 연결할 수 있습니다.

AI 연구 도우미 사용

현재 AI Demo는 가상 표본을 규칙 엔진과 Mock AI로 검토해 근거·불확실성을 보여줍니다. AI 적합 의견은 자동 승인이 아니며, AI는 제외 판정을 뒤집지 못합니다. 실제 음원 내용은 직접 감상하고 사람이 승인해야 합니다. 공급자 API 설정과 실검색은 별도 최종 검증 전까지 실행하지 않습니다.

장르 정확도 숫자 읽기

추천 정밀도는 앱이 적합으로 추천한 라벨 표본 중 사람이 실제 적합으로 확인한 비율입니다. 제외 오류율은 앱이 제외했지만 사람이 적합으로 확인한 비율입니다. 표본이 적거나 불확실 라벨뿐이면 측정 전으로 표시하며 95% 달성을 주장하지 않습니다.

계정과 데이터를 안전하게 관리하기

Google 계정을 연결한다고 일본 현지 유튜브 홈 추천이 바뀌는 것은 아닙니다. 앱은 공식 데이터 API를 이용하는 조회 전용 도구입니다. VPN과 무관하며, 반복 자동시청·댓글 자동게시·좋아요·구독 매크로는 제공하지 않습니다.
배포 ZIP 실행과 해시 확인

ZIP은 반드시 모두 압축 해제하고 EXE와 _internal을 한 폴더에 둡니다. 같은 Actions 아티팩트의 RELEASE_SHA256SUMS.txt가 ZIP 해시 기준이며, 압축 해제 후 SHA256SUMS.txt가 EXE 해시 기준입니다. 해시가 다르면 실행하지 말고 다시 내려받으세요. 게시자 코드 서명이 없는 배포본에는 SmartScreen 경고가 나타날 수 있습니다.

소스 실행과 EXE는 다릅니다

OAuth_모듈_설치하기.bat은 Python으로 소스를 실행할 때만 사용하는 설치 도구이며 Python 3.10+가 필요합니다. EXE 배포판에는 Python과 OAuth 모듈이 포함되어 있으므로 이 배치 파일을 실행하지 않습니다.

최종 실전 순서
  1. GitHub Actions 배포 ZIP 받기
  2. 전체 압축 해제 후 EXE 및 SHA-256 확인·실행
  3. Google Cloud에서 데스크톱 OAuth 설정
  4. Morning Chill 조사 계정 연결
  5. 실제 JP/KR 후보 검색
  6. 직접 감상 라벨로 정밀도와 제외 오류율 측정
비밀번호와 JSON을 보내지 마세요.

JSON 파일은 각 사용자가 자신의 PC에서 선택하며, 승인 토큰은 개인 PC의 %LOCALAPPDATA%\ZisuResearchStudio\oauth_tokens에 저장됩니다. 기존 ZISU V2 데이터를 유지하기 위해 데이터베이스는 삭제하지 않습니다. 기존 DB를 백업한 뒤 업데이트를 진행하세요.

자주 발생하는 오류

EXE를 열 때 모듈/런타임 오류 → ZIP을 다시 전체 압축 해제하고 EXE 옆에 _internal 폴더가 있는지 확인합니다. EXE 배포판에서 OAuth 설치 배치를 실행할 필요는 없습니다.

Python 소스 실행에서 모듈이 없습니다 → Python 3.10+ 환경에서만 OAuth_모듈_설치하기.bat을 실행합니다.

이 앱은 확인되지 않았습니다 / access blocked → 최종 실전 OAuth 단계에서 Google Cloud 테스트 사용자와 동의 화면 상태를 확인합니다.

데스크톱 앱이 아닙니다 → 웹 앱용 JSON이 아닌 데스크톱 앱 OAuth JSON 사용.

유튜브 채널이 없습니다 → 조사 전용 계정은 채널 없이도 연결할 수 있습니다(YouTube API 이용 가능 여부는 Google 정책에 따름).

실행 안 됨 → 검증 CMD 결과를 확인하고, 실제 데이터나 DB를 삭제하지 마세요. OAuth 실전 연결 이후에는 오류진단하기.bat으로 개인정보 없는 진단 정보를 확인할 수 있습니다.

V4.5.1 AI 키 보안 및 조사 재개 추가 안내

AI 탭에서 OpenAI/Gemini 키를 저장·변경·삭제할 수 있습니다. 입력란은 마스킹되며 키는 Windows 현재 사용자 DPAPI로 암호화되어 사용자 데이터 폴더에 저장됩니다. 키는 다시 표시되지 않으며, Google OAuth 토큰 저장소와 분리되어 있습니다.

유료 AI는 기본 OFF입니다. 공급자의 최신 가격을 사용자가 확인하고 안전 여유를 둔 1회 예상 비용과 일일 USD 한도를 입력하고, 매 실행을 확인해야 합니다. 앱은 요금이나 무료 할당량을 가정하지 않으며 공급자별 작업당 10회·프로필별 일 30회로 중단합니다. 입력 비용은 호출 차단용 추정치이며 실제 청구액을 보장하지 않습니다. 비용을 확인할 수 없다면 규칙 전용 또는 Ollama를 이용하세요.

일시 정지한 조사는 같은 프로필에서 이어갈 수 있습니다. 검색 요청 중 앱이 종료되어 완료 여부가 불확실하면 해당 읽기 검색을 재시도할 수 있으므로 YouTube 할당량이 추가 소모될 수 있습니다. 이미 확인한 후보 ID는 중복 제거됩니다.

공급자 HTTP 오류·응답 본문은 원문 그대로 화면이나 보고서에 표시하지 않습니다. AI 의견은 사람 판정이 아니며 실제 음원은 직접 감상해야 합니다.

V4.5.2 호환성 및 비용 안내

Gemini 2.5와 Gemini 3은 서로 다른 공식 구조화 응답 포맷으로 요청하며, Mock 계약 테스트만 수행했습니다. 실제 API 연결은 검증하지 않았습니다.

화면의 1회 비용과 일일 한도는 사용자가 입력하는 호출 차단용 예상 예산이며 실제 청구액을 보장하지 않습니다. NaN, 무한대, 0, 음수, 잘못된 값은 거부됩니다.

V4.5.3 Gemini 1회 연결 확인

AI 연구 도우미의 Gemini 실제 연결 테스트 (1회)를 사용하면 YouTube/OAuth 없이 지정된 가상 일본어 메타데이터만 전송합니다. 보안 입력란에 DPAPI 저장된 키가 있어야 하며, 예상 비용과 프로젝트 과금 가능성을 확인한 뒤 최종 승인해야 합니다. 승인 취소는 요청 0회이고, 실패 시 자동 재시도하지 않습니다. 키·응답 원문은 화면이나 로그에 남기지 않습니다.

이 테스트는 임시 데이터베이스만 사용합니다. 실제 비용은 공급자 대시보드에서 확인하세요. API 키는 공유하지 말고 결과의 오류 코드/상태만 공유하세요.
