ZISU Research Studio V3 — 첫 실행 가이드
=======================================
1. 기존 V2.1 프로그램은 삭제하지 마세요.
2. 이 ZIP을 새 폴더에 전체 압축 해제합니다.
3. '실행하기.bat'을 더블클릭합니다. 기존에 V2.1이 정상 실행되었다면 Python은 있을 가능성이 높습니다.
4. 첫 화면 '① 계정 연결'에서 Morning Chill Rap JP 프로필을 확인합니다.
5. 간편 체험은 'Google Cloud 없이 먼저 유튜브 열기'로 웹 검색부터 시작할 수 있습니다.
   실제 앱 계정 연결은 다음 OAuth 단계가 필요합니다.
6. 처음 한 번 'OAuth_모듈_설치하기.bat'을 실행합니다.
7. Google Cloud의 YouTube Data API v3와 Desktop OAuth 클라이언트를 준비하고 JSON 파일을 선택합니다.
8. [2. 새 계정으로 Google 로그인 및 연결] → 새 Google 계정 선택 → 이메일/채널명을 확인한 뒤 승인합니다.
9. '② 장르별 채널 검색' 탭에서 일본 모닝칠랩 전용 검색어로 후보를 찾습니다.

* Google Cloud OAuth JSON은 Gmail 비밀번호가 아닙니다. 채팅/깃허브/지인에게 보내지 마세요.
* YouTube Data API 검색은 일본 지역의 시청 가능한 검색결과이지, 현지 운영자 인증이나 내 YouTube 홈 추천 피드가 아닙니다.
* OAuth 연결/실 API 테스트/Windows EXE는 아직 실제 사용자 환경에서 검증되지 않았습니다.
* 로그인 연결이 어려우면 Google 연결 없이 검색어를 고르고 '유튜브 검색 열기'로 시작할 수 있습니다.
* 문제가 나면 '오류진단하기.bat'을 실행해 메시지를 확인하세요. 개인 인증정보는 전달하지 마세요.
