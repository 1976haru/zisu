ZISU 실행 문제 해결

가장 흔한 원인은 Python 3.10 이상 미설치 또는 ZIP에서 파일 일부만 꺼낸 경우입니다. 기존 자료는 삭제하지 마세요.

1단계 — 전체 압축 풀기

ZIP을 마우스 오른쪽 클릭하고 모두 압축 풀기를 선택하세요. main.py, mcrs 폴더, 실행하기.bat가 한 폴더 안에 있어야 합니다.

2단계 — Python 설치 확인

실행하기.bat을 다시 더블클릭해 보세요. Python 설치 안내 창이 뜨면 Python 공식 다운로드에서 Windows 64-bit Python 3.12 또는 3.13을 설치하세요. 설치할 때 Add python.exe to PATH를 선택할 수 있으면 체크하세요. 처음 설치 후 기존 명령 프롬프트를 닫았다가 다시 실행하세요.

3단계 — 여전히 실행이 안 된다면

오류진단하기.bat을 더블클릭하면 메모장에 진단 결과가 열립니다. 그 내용을 채팅에 복사해 주세요. 계정 비밀번호나 API 키를 넣지 마세요.

로컬 작업 경로

개발 경로는 D:\03 zisu입니다. 하지만 우선 어디에 압축을 풀든 해당 폴더에서 바로 실행 가능합니다. GitHub 동기화나 기존 폴더 덮어쓰기는 아직 하지 마세요.

참고: 이 ZIP은 Python 소스 버전이며 EXE가 아닙니다. Python 설치 없이 작동하는 정식 Windows EXE는 Windows 빌드와 검증이 필요합니다.
