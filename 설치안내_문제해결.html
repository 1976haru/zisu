ZISU V4.4 실행 문제 해결

기존 자료를 삭제하지 마세요. 공식 Actions 배포 ZIP을 모두 압축 풀기한 뒤 실행해야 합니다.

1단계 — EXE와 해시 확인

ZisuResearchStudio.exe와 SHA256SUMS.txt가 같은 폴더에 있어야 합니다. Get-FileHash .\ZisuResearchStudio.exe -Algorithm SHA256 결과를 비교하세요.

2단계 — SmartScreen

코드 서명이 없는 RC에서는 Defender SmartScreen 경고가 나타날 수 있습니다. GitHub Actions 공식 아티팩트와 SHA-256이 일치할 때만 실행하고, 출처 불명의 EXE는 실행하지 마세요.

3단계 — 데이터 폴더 오류

앱이 사용자 데이터 폴더를 열 수 없다고 표시하면 디스크 여유 공간과 %LOCALAPPDATA%\ZisuResearchStudio의 쓰기 권한을 확인하세요. 전체 폴더 권한을 무작정 변경하거나 기존 DB를 삭제하지 마세요.

소스 버전

실행하기.bat을 사용하는 개발용 소스 배포에만 Python 3.10 이상과 tkinter가 필요합니다. 정식 EXE는 프로젝트 소스 경로에 의존하지 않습니다.
